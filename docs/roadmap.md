# План развития iTime

## Готово: v1

- [x] 16×2 WH1602A по параллельному интерфейсу 4-bit.
- [x] ESP-WROOM-32, Wi-Fi 2,4 ГГц.
- [x] Время из NTP, фиксированное UTC+4.
- [x] Дата и время на двух строках LCD.
- [x] Проверенный обход нестабильного запуска при Flash 80 МГц: 40 МГц/DIO.
- [x] PowerShell/Arduino CLI команды и диагностические заметки.

## План: v2 — погода

- [ ] Небольшое серверное API JSON с температурой и погодой.
- [ ] Автоматическая смена экрана между часами и погодой.
- [ ] Состояния «нет сети» / «нет свежих данных».

## План: v3 — новости

- [ ] Получение подготовленных заголовков из собственного Python-сервера [news_informer_project](https://github.com/iXimik/news_informer_project).
- [ ] Бегущая строка длиной 16 символов.
- [ ] Очередь новостей, дедупликация, таймауты.
- [ ] Кодировка кириллицы для конкретного знакогенератора ЖКИ.

## План: v4 — панель управления

- [ ] Настройки обновлений, источников, города и часов.
- [ ] Проверить [CRMui3](https://github.com/WonderCRM/CRMui3) на совместимость с используемой версией Arduino Core ESP32.
- [ ] Авторизация веб-интерфейса, хранение настроек без утечки паролей.

Никакая из перечисленных будущих функций не объявляется реализованной.
